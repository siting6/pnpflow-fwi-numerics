# PnP-Flow FWI: the three main tables

Code, inputs, settings and per-run measurements behind Tables 4.1-4.3 of
"An exploration of plug-and-play flow matching for full-waveform inversion on breast imaging":
PnP-Flow versus TV-FWI on 50 constant-background circle targets, 50 Gaussian-background circle targets
and 32 numerical breast phantom patches. Every reconstruction starts from the constant field 8 and uses
exactly 2,500 data updates. PnP-Flow is run with four seeds per target, TV-FWI once.

## Rebuild the tables (CPU, seconds)

Python 3.11:

```bash
python -m pip install -r requirements.txt
python reproduce/make_tables.py --check   # rebuild results/tables.md and compare with the printed values
python -m pytest -q
```

`make_tables.py` reads the 792 bundled error rows in `results/measurements.csv` (one per reconstruction
plus one per constant start), writes `results/tables.md`, and compares 18 table entries and six win counts
with `results/expected.json`. For each target the median over the four PnP-Flow seeds is taken first, then
the median over the targets. Relative L2 error is in percent; contrast error is in model units.

## Rescore the reconstructions (CPU, seconds)

The 660 reconstructions (528 PnP-Flow, 132 TV-FWI) are deposited separately (see Deposit). Each file holds
the target, the estimate and the settings of its run, laid out as `<cohort>/<method>/image<i>[_seed<s>].npz`.

```bash
python reproduce/score.py /path/to/archive --archive --output scored
python reproduce/make_tables.py --measurements scored/measurements.csv --output scored/tables.md --check
```

`--archive` requires the SHA-256 of every file to match `results/sources.json`; the scorer then recomputes
both errors from the saved fields. Rescoring the deposited files reproduces `results/measurements.csv` exactly.

## Recompute the reconstructions (GPU, about ten hours)

```bash
python -m pip install -r requirements-gpu.txt   # CUDA 12 JAX and PyTorch
python reproduce/run_experiments.py --dry-run
python reproduce/run_experiments.py              # writes runs/<cohort>/<method>/image<i>[_seed<s>].npz
python reproduce/score.py runs --output runs/scored
python reproduce/make_tables.py --measurements runs/scored/measurements.csv --output runs/tables.md --check
```

Each reconstruction is a separate process (`reproduce/reconstruct.py`) and takes about 58 s (PnP-Flow) or
52 s (TV-FWI) on an NVIDIA RTX 6000 Ada with JAX 0.6.0 and PyTorch 2.5.1. The launcher checks the input and
checkpoint checksums first and skips completed runs on restart. A subset, for example
`--cohort flat --images 0 --seeds 0`, is useful as a trial; the tables need every target and all four seeds.
The two priors are read from `checkpoints/`, or from the files named by `PNPFLOW_CKPT_FLAT` and
`PNPFLOW_CKPT_GAUSS`.

Floating-point results depend on the GPU model. On the RTX 6000 Ada, this code reproduces the reconstruction arrays of the deposited files
bit for bit (checked with one PnP-Flow and one TV-FWI run on each test set); the saved files also hold elapsed times, which vary between runs. On other GPUs the fields differ
in the last bits and the table entries may move slightly, which is why `--check` compares with the printed
values instead of requiring identical fields.

## Experiment

Two-dimensional acoustic wave equation on the unit square, discretized on 64 x 63 points (periodic in x, Neumann
top and bottom; the bundled fields are 64 x 64 and the last column is dropped before inversion), with twelve plane-wave
shots: a Ricker flux applied uniformly along the top boundary with peak frequencies 3, 4, ..., 14. All 63 bottom
points record every second of 1,000 time levels. Data are noiseless and generated by the same solver.

- **PnP-Flow.** 50 blocks of 50 data updates: Adam without bias correction, gradients clipped to norm 10,
  moments reset at every block, step 0.1 (1 - t), where the flow time t advances from 0.5 to 1 over the run.
  Each block ends with a prior update that averages eight one-step denoising proposals
  D_t(x) = z + (1 - t) v(z, t) with z = (1 - t) eps + t x and eps ~ N(0, I); seeds 0-3 set the Gaussian draws.
- **TV-FWI.** 2,500 Adam updates (same clipping, moments carried) on the data misfit plus weight times the
  smoothed isotropic total variation (eps = 1e-4); weight/step 0.0003/0.1 for the constant-background circles
  and 0.003/0.01 for the two other sets.
- **Priors.** Two flow-matching U-Nets, trained on constant-background circles (Table 4.1) and on
  Gaussian-background circles (Tables 4.2 and 4.3). `checkpoints/` holds their EMA weights;
  `configs/checkpoints.json` records sizes and SHA-256.
- **Metrics.** Relative L2 error of the whole field, and contrast error: the contrast of an inclusion is the mean
  over its eroded core minus the mean over the ring 2-5 pixels away that excludes all inclusions; circle targets
  average the absolute contrast error over their inclusions, breast patches use the designated target lesion.

All settings are in `configs/experiments.json` and `reproduce/reconstruct.py`. Prior training and the selection
of the settings are outside this package.

## Files

```
pnpflow_fwi/    wave.py: solver, receivers, misfit and gradient; inversion.py: PnP-Flow, TV-FWI and their
                shared Adam step; unet.py: velocity network; prior.py: checkpoint loading, one-step denoiser
reproduce/      common.py: settings, file layout, result validation, metrics; reconstruct.py: one run;
                run_experiments.py: launcher; score.py; make_tables.py
configs/        experiments.json: budgets, seeds, per-set TV weight and step, input checksums; checkpoints.json
data/           flat/, gauss/, breast/: targets in data_test.npz (breast: with lesion masks), metadata, records
checkpoints/    the two EMA priors (71 MB each)
results/        measurements.csv, expected.json (printed values), tables.md, sources.json (archive checksums)
tests/          CPU tests, run by .github/workflows/tables.yml
```

## Data sources

The breast patches are derived from "2D Acoustic Numerical Breast Phantoms and USCT Measurement Data"
(Harvard Dataverse, [doi:10.7910/DVN/CUFVKE](https://doi.org/10.7910/DVN/CUFVKE), CC0 1.0); speeds in m/s are
mapped to model units by 8/1450. The circle targets were generated for this work; the generator is not part of
this package, the exact test arrays are.

## Deposit

The reconstruction archive, `pnpflow-fwi-main-tables-archive.tar.gz` (13.7 MB, 660 files,
SHA-256 `6ccde6d080b440f845af755c3e3c2d26f9fed2c6b082631cf2225cca3976a3a2`), unpacks to the `archive/`
folder expected by `score.py --archive`. It is deposited together with copies of the two checkpoints.
